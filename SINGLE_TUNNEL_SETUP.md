# Single Tunnel Deployment Guide

## Overview

This setup allows both your Vue.js frontend and Flask backend to be served through a **single ngrok tunnel**, making it easy for others to access your app with one URL.

## How It Works

- **Flask** serves both the static Vue.js files (from `frontend/dist`) AND the API endpoints
- **Visitors** access one URL (the ngrok tunnel) for everything
- **Automatic routing**: API calls go to Flask, other routes served as Vue.js SPA

## Architecture

```
┌─────────────────────────────────────────┐
│   https://xxxxx.ngrok-free.dev          │
│   (Single ngrok tunnel)                 │
└──────────┬──────────────────────────────┘
           │
           ├─→ /api/*     → Flask API endpoints
           ├─→ /js/*      → Vue.js JavaScript
           ├─→ /css/*     → Vue.js Stylesheets
           ├─→ /*         → Vue.js app (index.html)
           │
           └─→ WebSocket  → Socket.io (/socket.io)
           
   Backend (Flask on localhost:5000)
   ├─ Serves static files from frontend/dist
   ├─ API routes (/api/*)
   └─ WebSocket (Socket.io)
```

## Setup Steps

### 1. Build the Frontend
```powershell
cd frontend
npm run build
```
This creates `frontend/dist/` with optimized production files.

### 2. Start the Backend
```powershell
cd backend
python run.py
```
Backend runs on `http://localhost:5000` and serves the Vue.js files.

### 3. Create ngrok Tunnel
```powershell
ngrok http 5000
```

Get the URL from ngrok output, e.g.:
```
Forwarding: https://rewarding-fredrick-balancedly.ngrok-free.dev -> http://localhost:5000
```

### 4. Share the ngrok URL
Give others this URL to access your app:
```
https://rewarding-fredrick-balancedly.ngrok-free.dev
```

## Configuration

### Production (Flask-served)
When accessed through ngrok, the app **automatically** uses the current origin for API calls:
- Frontend runs on: `https://rewarding-fredrick-balancedly.ngrok-free.dev`
- API calls go to: `https://rewarding-fredrick-balancedly.ngrok-free.dev/api/...`
- WebSocket connects to: `wss://rewarding-fredrick-balancedly.ngrok-free.dev`

**No configuration needed** — it just works!

### Development (npm run serve)
If you want to develop with hot-reload (`npm run serve`), you'll use the `.env.local` file:

**`.env.local`** (for local development):
```
VUE_APP_BACKEND_IP=localhost
VUE_APP_BACKEND_PORT=5000
VUE_APP_BACKEND_PROTOCOL=http
```

Then run both:
```powershell
# Terminal 1: Frontend dev server
npm run serve  # runs on localhost:8080

# Terminal 2: Backend
python run.py  # runs on localhost:5000
```

## Important Files Modified

### Backend Changes
**`backend/app/__init__.py`**
- Configured Flask to serve static files from `frontend/dist`
- Added catch-all route that serves `index.html` for Vue Router
- API routes still function normally under `/api/` prefix

### Frontend Changes
**`frontend/src/common/config.js`**
- Smart configuration: detects development vs. production
- **Development**: Uses `VUE_APP_*` environment variables from `.env.local`
- **Production**: Uses `window.location` (works with any domain, including ngrok)

**`frontend/.env.local`**
- Used only during local development (`npm run serve`)
- Ignored in production builds

## Workflow for Multiple Users

1. **Final Build**: Run `npm run build` once
2. **Start Backend**: `python run.py` (serves frontend + API)
3. **Share ngrok URL**: Others access the single URL
4. **Updates**: Modify code → `npm run build` → restart backend

## Troubleshooting

### "404 on app routes"
Make sure you've run `npm run build` after making frontend changes.

### "WebSocket connection fails"
ngrok free tier has some limitations. If issues persist:
- Try restarting ngrok
- Check browser console for error details
- Ensure backend is running on port 5000

### "API calls still failing"
- Clear browser cache (Ctrl+Shift+Delete)
- Check Network tab in DevTools
- Verify backend is running: `http://localhost:5000`

## Reverting to Separate Tunnels (Option 1)

If you prefer two tunnels instead:

1. **Backend tunnel**: `ngrok http 5000`
2. **Frontend dev server**: `npm run serve` (runs on localhost:8080)
3. **Or frontend tunnel**: `ngrok http 8080`
4. **Then update** `.env.local` with two URLs

## Production Considerations

For production deployment (beyond ngrok):
- Build: `npm run build`
- Copy `frontend/dist/*` → `backend/app/static/` (or use as is)
- Deploy Flask backend with ngrok or own domain
- CORS and SocketIO already configured to accept all origins
